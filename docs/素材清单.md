# 正式版素材清单

Demo 里的单位和建筑都是用代码拼出来的几何体，音效是浏览器实时合成的。正式版按这份清单替换。

## 原则

1. **授权优先**：只用 CC0（随便用，不用署名）或明确允许商用的素材。每个素材在 `assets/CREDITS.md` 里记一行：名称、来源链接、作者、授权。
2. **风格统一比单件精细更重要**：同一类素材尽量出自同一个素材包或同一个作者。
3. **不追求超高面数**：俯视镜头下一个小兵在屏幕上只有二三十像素，几千面就够；面数太高会让网页卡顿。

## 规格

| 类型 | 格式 | 规格 |
| --- | --- | --- |
| 3D 模型 | `.glb`（glTF 二进制） | 小兵 ≤ 3000 面，主角和重甲虫 ≤ 5000 面，虫后 ≤ 15000 面，建筑 ≤ 20000 面；Y 轴朝上，模型正面朝 +X；1 单位 = 游戏里 1 像素 |
| 骨骼动画 | 打包在 `.glb` 里 | 动画名用英文：`idle`、`run`、`shoot`、`attack`、`die`；能找到就要，找不到我用程序做简单动画 |
| 贴图 | `.jpg`（颜色）/ `.png`（法线、粗糙度） | 地面 2048×2048 可平铺；单位 1024×1024 以内 |
| 音效 | `.ogg`（备选 `.mp3`） | 单声道，44.1 kHz，单个 ≤ 200 KB |
| 音乐 | `.ogg` | 立体声，可循环，每首 ≤ 5 MB |

## 推荐来源

以下网站都提供可免费商用的素材。具体素材包的名字和授权请以网站页面为准，下载前看一眼授权说明。

| 需要什么 | 先去哪找 | 搜索关键词 | 授权 |
| --- | --- | --- | --- |
| 陆战队员、机甲、运输机 | Quaternius（quaternius.com） | sci-fi、mech、soldier、space | CC0 |
| 外星虫子、怪物 | Quaternius、Poly Pizza（poly.pizza） | monster、alien、insect、bug | CC0 为主，Poly Pizza 有些是 CC BY，需署名 |
| 科幻建筑、炮塔、道具 | Kenney（kenney.nl） | space kit、tower defense、blaster | CC0 |
| 地面贴图 | Poly Haven（polyhaven.com）、ambientCG（ambientcg.com） | sand、rocky ground、metal plate、organic | CC0 |
| 音效 | Kenney 音效包、Sonniss GDC 免费合集、Freesound（筛选 CC0） | gunshot、explosion、creature、slime | CC0 / 免版税 |
| 音乐 | OpenGameArt、Incompetech | epic、military、dark ambient | 多为 CC BY，需在游戏里署名 |
| 专属造型（虫后、虫巢） | Meshy、Tripo（AI 生成 3D）；Suno（AI 音乐） | — | 看各平台条款，商用通常要付费套餐 |

## 优先级

先换最影响观感的，按顺序来：

1. 地面贴图（沙地、菌毯、金属地板）：一换整个画面质感就上来了
2. 主角、机枪兵、甲虫、喷吐虫：屏幕上出现最多
3. 枪声、爆炸、虫子死亡、酸液音效
4. 战斗音乐
5. 建筑：基地、兵营、炮塔、虫巢、孵化池、虫塔
6. 其余兵种、野怪、装饰物
